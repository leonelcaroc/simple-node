# Simple Node

This is a simple Express.js application that allows you to manage a list of fruits. You can add, update, retrieve, and delete fruits. The app uses the `uuid` library for generating unique identifiers and the `cors` package for enabling Cross-Origin Resource Sharing.

## Prerequisites

- [Node.js](https://nodejs.org/) (Version 14 or above)
- [Yarn](https://yarnpkg.com/) (Optional, but recommended)

## Setup Instructions

Follow these steps to set up the project locally:

### 1. Clone the Repository

Clone the project to your local machine:

```bash
git clone https://github.com/your-username/simple-node.git
```

### 2. Install packages

```bash
npm install
```

### 3. Run the app

```bash
npm run dev
```
